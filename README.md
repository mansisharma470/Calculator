# 🧮 Calculator

A simple and responsive calculator web application built using **HTML, CSS, and JavaScript**.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Decimal number support
* 🧹 Clear/reset functionality
* 📱 Responsive design
* 🖱️ Interactive buttons

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Calculator functionality and DOM manipulation

## 📂 Project Structure

```text
Calculator/
│
├── index.html
├── style.css
├── script.js
└── Resources/
    └── images/icons (if any)
```

## 🚀 How to Use

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start calculating! 🎉

## 🎯 Purpose

This project was created to practice **JavaScript, DOM manipulation, event handling, and responsive web design**.
